## J.A.R.V.I.S. v0.1.0 (Beta)

Your personal AI assistant for Windows: say **"Hey Jarvis"** and control your PC with your voice.

### Install
1. Install [Ollama](https://ollama.com/download) (free, runs the AI on your PC).
2. Download and run **Jarvis-Setup.exe** below.
3. Open Jarvis and click **Sign in with browser** (create an account on the website if you don't have one).
4. The first start downloads the AI model (~3.3 GB) and the speech model (~0.5 GB).

Windows SmartScreen may warn because the app isn't code-signed yet: click **More info → Run anyway**.

### What's inside
- "Hey Jarvis" wake word, offline speech recognition, British neural voice, push-to-talk `Ctrl+Alt+J`
- Local AI brain (Qwen3-VL via Ollama) with 29 PC skills: apps, files, web, YouTube, volume, media, brightness, timers, typing, power
- Live news, web search, weather, system status, clipboard
- Screen and webcam vision
- Confirmations before risky actions, protected apps (WhatsApp by default)
- Iron Man–style HUD with live diagnostics, news panel and tray icon

### Requirements
Windows 10/11 64-bit · 8 GB RAM (16 GB recommended) · NVIDIA GPU with 4+ GB VRAM recommended · ~6 GB free disk · microphone
